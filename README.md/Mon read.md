# 🚀 Project: AfriTalent Platform

Bienvenue sur le dépôt officiel du projet **AfriTalent**, une plateforme web moderne et intuitive conçue pour mettre en relation les meilleurs freelances et les entreprises en Afrique. 

Ce projet a été entièrement développé à l'aide de **HTML5**, **CSS3** et du framework **Bootstrap 5** pour garantir une expérience utilisateur fluide, responsive et professionnelle.

## ✨ Fonctionnalités Clés

* **Design Responsive & Moderne** : Une interface soignée s'adaptant parfaitement sur mobile, tablette et ordinateur grâce à la grille Bootstrap.
* **Compteurs Dynamiques** : Animation fluide des statistiques clés au défilement de la page (freelances inscrits, projets réalisés).
* **Foire Aux Questions (FAQ) Interactive** : Un système d'accordéon fluide géré pour répondre aux questions fréquentes des utilisateurs.
* **Carrousel de Témoignages** : Défilement dynamique des retours d'expérience de nos clients et freelances.
* **Formulaire de Contact Validé** : Section complète avec formulaire fonctionnel, coordonnées locales et intégration d'une carte interactive Google Maps (Dakar, Sénégal).
